# אתר שיווק דיגיטלי ובניית אתרים 🚀

דף נחיתה מודרני, מהיר ומותאם לקידום (SEO) שנבנה עבור העסק שלי.

## תכונות עיקריות:
* **עיצוב רספונסיבי:** מותאם מלא לניידים וטאבלטים.
* **מערכת חבילות:** הצגת מחירים ברורה (Starter, Growth, Premium).
* **FAQ דינמי:** רכיב שאלות נפוצות מובנה ב-React.
* **הנעה לפעולה:** כפתורי וואטסאפ מובנים עם הודעות מותאמות אישית.

## טכנולוגיות:
* React.js
* CSS3 (Flexbox & Grid)
* Vercel (Hosting)

## יצירת קשר:
לשאלות נוספות ניתן לפנות אלי בוואטסאפ דרך האתר.
